How credits work

  • Owner phone, WhatsApp, and email are hidden until you buy a plan.
  • Each new property uses 1 credit from Starter (4), Plus (10), or Pro (25).
  • Full-time WhatsApp and call support is included only with Pro. Starter and Plus do not include it.
  • Call and WhatsApp on the same listing count as one unlock.
  • Once a listing is unlocked, it stays unlocked for your account even if credits later hit zero.

Sandbox mode is ready in code. Add Razorpay test keys to start taking test payments.

Razorpay is in test mode. No real money is charged. Google Pay / PhonePe app buttons (UPI Intent) appear only in live mode on a real phone. In test checkout look for UPI (UPI ID or QR), not those app logos. The UPI ID is prefilled as success@razorpay — tap Pay. Use failure@razorpay to simulate a decline. If UPI is missing, enable it in Razorpay Dashboard → Account & Settings → Payment Methods, then retry. Cards: do not use 4111 1111 1111 1111 (Indian accounts reject it as international). Use Mastercard 5267 3181 8797 5449, any future expiry, any CVV, then tap Success.
